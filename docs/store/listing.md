# Play 스토어 등록 정보 (복붙용)

**앱 이름**: MyHumidor

**간단한 설명 (80자)**
내 휴미더 재고와 시가 테이스팅 노트를 기록하고, 취향에 맞는 시가를 찾아보세요.

**자세한 설명**
MyHumidor는 시가 애호가를 위한 개인 기록 앱입니다.

• 휴미더 재고 — 휴미더별로 보유 시가, 수량, 입고일, 숙성 일수를 한눈에
• 테이스팅 다이어리 — 공식·리뷰 노트에서 느낀 향을 체크하고 초반/중반/후반 메모와 점수 기록
• 2,600여 라인 시가 DB — 브랜드·라인 검색, 공식 노트와 리뷰어 노트 참고
• 밴드 스캔 — 카메라로 밴드를 찍으면 시가를 자동 인식 (하루 3회)
• 취향 추천 — 내가 높게 평가한 시가와 비슷한 시가 추천
• 도감·미각 업적 — 경험한 브랜드와 구분해 낸 노트로 성장 확인
• 백업 — JSON 내보내기/가져오기

모든 기록은 내 폰 안에만 저장됩니다. 회원가입 없음, 광고 없음, 판매 없음.
본 앱은 담배 제품을 판매하거나 광고하지 않으며, 만 19세 이상 성인을 위한 기록 도구입니다.
